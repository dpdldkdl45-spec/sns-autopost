Effective date / 시행일: 2026-09-20 · Applies to: SNS Autopost (https://dpdldkdl45-spec.github.io/sns-autopost/)

This Privacy Policy explains what information SNS Autopost (the "API Client") accesses, collects, stores, uses, shares and deletes, and how you can revoke its access. SNS Autopost is operated by an individual developer (the "operator") for the operator's own use only. The operator must read and agree to this Privacy Policy before authorizing and using SNS Autopost.

본 방침은 SNS Autopost(이하 "API 클라이언트")가 어떤 정보에 접근·수집·저장·이용·공유·삭제하는지, 그리고 접근 권한을 어떻게 철회할 수 있는지 설명합니다. SNS Autopost는 개인 개발자(이하 "운영자")가 본인 용도로만 운영하며, 운영자는 SNS Autopost를 승인·사용하기 전에 본 방침을 읽고 동의해야 합니다.

1. Use of YouTube API Services

SNS Autopost uses YouTube API Services (the YouTube Data API) to upload videos to YouTube channels owned or managed by the operator. By using SNS Autopost, you agree to be bound by the YouTube Terms of Service (https://www.youtube.com/t/terms).

Information handled through YouTube API Services is also subject to the Google Privacy Policy (http://www.google.com/policies/privacy).

SNS Autopost는 운영자가 소유·관리하는 YouTube 채널에 영상을 업로드하기 위해 YouTube API 서비스(YouTube Data API)를 사용합니다. SNS Autopost를 사용하면 YouTube 이용약관에 구속되는 데 동의하는 것입니다. YouTube API 서비스를 통해 처리되는 정보에는 Google 개인정보처리방침도 적용됩니다.

2. Who uses SNS Autopost

SNS Autopost has exactly one user: the operator. It is not offered to the public, has no sign-up, and never accesses YouTube channels or Google accounts of third parties. It runs without a user interface as a program on the operator's computer or server.

SNS Autopost의 사용자는 운영자 1인뿐입니다. 일반에 제공되지 않고 회원가입이 없으며, 제3자의 YouTube 채널이나 Google 계정에는 접근하지 않습니다. 화면 없이 운영자의 PC 또는 서버에서 프로그램으로 실행됩니다.

4. How information is used

The information above is used only to upload the operator's videos to the operator's own YouTube channels, set their title, description and scheduled publish time, confirm that they were published, and keep an operating record. It is not used for advertising, profiling, analytics, or any other secondary purpose.

위 정보는 운영자 영상을 운영자 본인 채널에 업로드하고, 제목·설명·예약 공개 시각을 지정하고, 공개 여부를 확인하고, 운영 기록을 남기는 데에만 사용합니다. 광고, 프로파일링, 분석 등 다른 목적으로 사용하지 않습니다.

Information may also be disclosed if required by law.

  • 외부: 판매·대여·제3자 제공을 하지 않습니다. 예외는 (a) 업로드 수행을 위해 요청을 보내는 Google/YouTube, (b) 운영자가 업로드 기록(영상 ID·일정·결과)을 보관하는 개인 작업 공간으로 쓰는 Notion Labs, Inc.뿐이며(단, 그곳의 영상 ID·상태도 7항의 30일 보관 한도를 따릅니다), 법령상 요구가 있는 경우 공개될 수 있습니다.

7. Data retention

  • OAuth tokens are kept only while the operator keeps using SNS Autopost, and are deleted when access is revoked or the tool is no longer used.
  • Data obtained from YouTube API Services (video IDs and status) is kept for no longer than 30 calendar days unless it is refreshed from the YouTube API; after that it is deleted or refreshed. At least every 30 days, SNS Autopost confirms that its authorization is still valid; if a token can no longer be refreshed, the related stored API data is deleted.
  • OAuth 토큰은 운영자가 SNS Autopost를 계속 사용하는 동안만 보관하며, 권한 철회 또는 사용 중단 시 삭제합니다.
  • YouTube API로 받은 데이터(영상 ID·상태)는 YouTube API에서 갱신하지 않는 한 30일을 넘겨 보관하지 않으며, 그 후 삭제하거나 갱신합니다. 최소 30일마다 인증이 유효한지 확인하고, 토큰을 더 이상 갱신할 수 없으면 관련 저장 데이터를 삭제합니다.

8. How to delete your data

  1. Delete data stored by SNS Autopost: Email dpdldkdl45@gmail.com with the subject "Data deletion request". The OAuth token file and all stored API data (video IDs, status and upload records) will be deleted as soon as possible and within 7 calendar days. The operator can also do this directly by deleting the local token file and the upload records.
  2. Revoke access through Google: In addition to the deletion procedure above, you can revoke SNS Autopost's access to your data at any time through the Google security settings page: https://security.google.com/settings/security/permissions. After revocation, all data SNS Autopost accessed or stored under that consent is deleted as soon as possible and within 7 calendar days.
  3. Revocation by SNS Autopost: When the operator withdraws consent through SNS Autopost's own procedure, SNS Autopost immediately revokes the token with Google (OAuth 2.0 token revocation endpoint) and deletes the local token file.

Important: Deleting data stored by SNS Autopost does not affect any data stored by YouTube. Videos already uploaded remain on YouTube. To delete videos or other data on YouTube, use YouTube (for example, YouTube Studio) or another authorized application that supports deleting that data.

  1. SNS Autopost가 저장한 데이터 삭제: dpdldkdl45@gmail.com로 제목 "Data deletion request" 메일을 보내면 OAuth 토큰 파일과 저장된 API 데이터(영상 ID·상태·업로드 기록)를 지체 없이, 늦어도 7일 이내에 삭제합니다. 운영자는 로컬 토큰 파일과 업로드 기록을 직접 삭제할 수도 있습니다.
  2. Google에서 권한 철회: 위 삭제 절차와 별도로, Google 보안 설정 페이지(https://security.google.com/settings/security/permissions)에서 언제든 SNS Autopost의 접근 권한을 철회할 수 있습니다. 철회 후 해당 동의로 접근·저장한 데이터는 지체 없이, 늦어도 7일 이내에 삭제합니다.
  3. SNS Autopost 자체 철회: 운영자가 SNS Autopost 절차로 동의를 철회하면 즉시 Google 토큰 철회 엔드포인트를 호출해 토큰을 무효화하고 로컬 토큰 파일을 삭제합니다.

유의: SNS Autopost가 저장한 데이터를 삭제해도 YouTube에 저장된 데이터에는 영향이 없습니다. 이미 업로드된 영상은 YouTube에 남습니다. YouTube의 영상 등을 삭제하려면 YouTube(예: YouTube 스튜디오) 또는 해당 삭제 기능을 지원하는 승인된 앱을 이용하세요.
