SNS Autopost

A private, unattended tool that uploads the operator's own pre-produced short-form videos to the operator's own YouTube channels at scheduled times, using the YouTube Data API (one of the YouTube API Services).

SNS Autopost는 운영자가 사전 제작한 숏폼 영상을 운영자 본인이 소유·관리하는 YouTube 채널에 예약 시각에 맞춰 자동 업로드하는 내부용 무인 도구입니다. YouTube API 서비스(YouTube Data API)를 사용합니다.

What this API client does

  • SNS Autopost is an internal tool used by a single individual operator. It has no public web interface, no sign-up, and no external users.
  • It runs as a Python program on the operator's computer or server and processes a schedule prepared in advance by the operator.
  • For each scheduled item, it uploads a video file that the operator produced and owns to a YouTube channel that the operator owns or manages.
  • It never uploads to, reads from, or manages YouTube channels belonging to third parties or other users.
  • It does not read comments, subscribers, analytics, or any viewer data.
  • 운영자 1인이 사용하는 내부 도구입니다. 공개 웹 화면·회원가입·외부 사용자가 없습니다.
  • 운영자의 PC 또는 서버에서 파이썬 프로그램으로 실행되며, 운영자가 미리 작성한 일정표를 처리합니다.
  • 각 일정 항목마다 운영자가 제작·소유한 영상 파일을 운영자 본인이 소유·관리하는 YouTube 채널에 업로드합니다.
  • 제3자나 다른 사용자의 YouTube 채널에는 업로드·조회·관리 작업을 하지 않습니다.
  • 댓글, 구독자, 분석 데이터, 시청자 정보는 읽지 않습니다.

How it uses the YouTube API

YouTube upload feature
Videos are uploaded to the operator's own YouTube channels, currently dpdldkdl.
업로드 대상: 운영자 본인 소유 YouTube 채널 (현재 dpdldkdl)
  1. Authorization (one time). The operator signs in with Google OAuth 2.0 and grants only the following scope:
    • https://www.googleapis.com/auth/youtube.upload — Manage your YouTube videos (upload only). Used to upload videos and set their title, description and visibility / scheduled publish time.
      YouTube 동영상 업로드 권한. 영상 업로드와 제목·설명·공개 상태·예약 공개 시각 지정에만 사용.
    The resulting OAuth refresh token is stored in a local file on the operator's own computer. The tool never asks for, receives, or stores YouTube or Google passwords.
  2. Upload. At the scheduled time the tool calls videos.insert to upload the video with the title and description the operator prepared.
  3. Visibility. The operator decides each video's visibility in advance. Videos are uploaded as private with a scheduled publish time (status.publishAt) chosen by the operator; YouTube then makes the video public at that time. The tool does not change the visibility of any other existing video.
  4. Confirmation. After the scheduled publish time, the tool looks up the status of that uploaded video (videos.list, part=status) to confirm it has become public.
  5. Result record. The tool records the returned video ID, the scheduled time and the result (success or error) in the operator's own local log files and the operator's private scheduling workspace (Notion), so the same video is not uploaded twice.
  1. 인증(1회): 운영자가 Google OAuth 2.0으로 로그인해 위 스코프만 허용합니다. 발급된 refresh token은 운영자 PC의 로컬 파일에 저장됩니다. YouTube/Google 비밀번호는 요청·수집·저장하지 않습니다.
  2. 업로드: 예약 시각에 videos.insert를 호출해 운영자가 작성한 제목·설명으로 영상을 업로드합니다.
  3. 공개 상태: 공개 여부는 운영자가 미리 정합니다. 영상은 비공개로 업로드되고 운영자가 정한 예약 공개 시각(status.publishAt)에 YouTube가 공개로 전환합니다. 다른 기존 영상의 공개 상태는 바꾸지 않습니다.
  4. 공개 확인: 예약 공개 시각 이후 해당 영상의 상태를 조회(videos.list, part=status)해 공개 전환을 확인합니다.
  5. 결과 기록: 중복 업로드 방지를 위해 반환된 영상 ID·예약 시각·결과(성공/오류)를 운영자 본인의 로컬 로그 파일과 운영자 전용 일정 관리 공간(Notion)에 기록합니다.

Data and privacy in short

  • No viewer or third-party personal data is collected.
  • Stored: the OAuth token (operator's computer) and upload records (video ID, schedule, result) in the operator's local logs and private Notion workspace.
  • Access can be revoked at any time at Google security settings.
